# Source Code

This repository uses two kinds of branches.

## Release documentation

`main` is the lightweight public branch for release notes, install instructions,
checksums, screenshots, and links to downloadable assets.

It does not contain the full Chia GUI source tree.

## Mod source

The current mod source is published on this branch:

```txt
akita-mod-source
```

Source URL:

```txt
https://github.com/twinedge39-web/Akita-autumn_field_console/tree/akita-mod-source
```

The v0.2.1 GitHub releases match this source commit. The older
`akita-nft-preview-dialog` branch is kept for existing links.

## Why split the branches?

Akita Autumn Field Console is an unofficial GUI mod based on Chia Network's
large upstream GUI tree.

Keeping `main` lightweight makes the public release page easier to inspect,
while the source branch keeps the full modified tree available for review.
